# Análisis de Requisitos

## Requisitos Funcionales
Especificación de las acciones concretas que el sistema debe poder realizar.
1.  **RF-01:** El sistema debe permitir...
2.  **RF-02:** El usuario podrá...
3.  **RF-03:** La aplicación generará...
4.  **RF-04:** La URL se regenerara....

## Requisitos No Funcionales
Restricciones y atributos de calidad del sistema.
*   **Rendimiento:** El tiempo de respuesta no excederá los X segundos.
*   **Seguridad:** Los datos sensibles deberán almacenarse de forma cifrada.
*   **Usabilidad:** La interfaz debe ser responsive.
